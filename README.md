# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 质量异常处置

出现**空片、连片、厚度偏差**时，在切片卡片上上报异常：记录异常类型、实测厚度（微米）、照片和发现人。上报后切片直接改回**研磨**，并退出观察与交付。

返工须填写返工原因、耗材批号、返工操作人，且返工后新厚度必须回到 **25~35 微米**；之后由**另一人**复核（复核人不能与返工操作人相同），通过后处置闭环，切片才能继续观察、样本才能交付。

- 重复上报沿用首次处置单编号（`QC-0001`…），处置单内累积每次上报记录。
- 钻孔编号更正会作废该样本下全部处置单；切片编号更正只作废该片处置单。处置单作废后不能继续返工/复核，须按新编号重新上报。

### 文件分工

| 文件 | 职责 |
| --- | --- |
| `quality-rules.js` | 规则判断：异常/返工/复校验、合格厚度区间、退出观察与交付、编号失效 |
| `quality-records.js` | 处置记录：上报、返工、复核、编号更正，独立存于 `data/quality-records.json` |
| `public/quality-page.js` | 页面操作：异常上报、返工登记、他人复核、编号更正面板 |

`server.js` 负责 HTTP 路由并在步骤记录、交付处调用规则拦截。
