# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 质量异常处置

- **规则判断**（`quality-rules.js`）：异常类型限定为空片、连片、厚度偏差；合格厚度区间 25-35μm；复核人必须是发现人/返工操作人之外的另一人。
- **处置记录**（`quality-records.js`）：报告异常时记录异常类型、实测厚度、照片、发现人，切片直接退回研磨并封锁，退出观察与交付；返工须填写原因和耗材批号，新厚度回到 25-35μm；另一人复核合格后才解除封锁。重复提交沿用首次处置编号（`QC-xxx`）；钻孔编号或切片编号更正会让处置中的异常单失效，需重新报告。
- **页面操作**（`quality-page.js`）：切片卡片内完成异常报告、返工登记、复核与编号更正，页面底部「质量异常处置记录」看板向车间展示全部返工与复核结果。
